# Crypto-Price-Predictor

This is an Stock Price Predictor that uses LSTM (Long Short-Term Memory) a neural network architecture for predicting price.

In Jupyter notebook file i have downloaded past 10 years data using yfinance. But in app i have used only past 1 year data for simplicity.

Using LSTM, we can say that it cannot predict an noisy data, since stock prices are noisy.
